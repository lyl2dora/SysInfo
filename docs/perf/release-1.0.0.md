## 分析（D79）

- 指令数与核类型无关，可以直接比较两台机器的工作量。CPU tab：M5 70.4 M 指令/s，M4 60.8 M 指令/s；总览：M5 56.7，M4 51.1。M4 做的活不比 M5 多，反而少 10% 左右。
- M4 这次的 D40 考核值是 1.696%，在预算内。同一工作量的历次结果为 1.58、2.34、3.03、2.54、1.70，原始 CPU 一直是 3.8–4.3%。
- 波动来自 D40 的折算：M4 上最快档时间只占 1–3%（约 0.1–0.2 s），用这么少的样本估出的「最快档每秒指令」很不稳定，同一次测量里两档就差了一倍（3.59 与 7.11 G/s）。
- 结论：M4 的「超出 2%」是考核口径的测量误差，不是 M4 上的额外开销。
