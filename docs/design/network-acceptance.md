# 网络模块验收报告

> 日期：2026-10-17。范围：D60–D62（分支 `module/network`）。边界实测、规格与偏离记录见 `docs/design/network.md`。

## 结论

- D60–D62 列的内容全部完成：
  - 数据：接口清单与分类（运行时按控制器与 SC 类型判断）、主接口（VPN 时取下层物理接口）、每接口 / 主接口 / 物理合计的入出速率、Wi-Fi（CoreWLAN，只在面板可见时读）、延迟（ICMP，默认关）、连接信息（地址、网关、DNS、代理）；
  - 界面：网速 widget（上下两行，出厂开）与延迟 widget（延迟开启后可选），面板 tab，设置页，诊断页，隐私页列出出站目标；
  - 公网 IP 按钮（D62，点击时查一次，服务地址第一次查询时填）；
  - 历史（主接口与每个物理接口每分钟；延迟开启时 RTT 与丢包）与「今日 / 本月」流量；CLI `network`。
- 全部用公开接口，没有新增私有层代码。
- 出厂默认与网络面板的开销都在 D19 预算内（§2）。
- 实现中有 10 处偏离规格，记在 `network.md` §8。请你验收时留意其中两处：
  - 面板压缩：Wi-Fi 与延迟合并成一张卡片；
  - 雷电 IP 端口一律不列出，由 Thunderbolt Bridge 代表。

## 2. 开销（`docs/perf/network.md`，D40 口径）

| 档位 | M5 | M4 |
|---|---|---|
| 出厂默认（五个 widget，新增网速；面板关闭，历史与能耗开启，新增网络历史每 60 s） | 0.34% | 0.36%* |
| 面板打开（网络 tab，速率 1 s，Wi-Fi 5 s，延迟关） | 0.82% | 0.53% |

- 预算：出厂默认 < 0.5%，面板打开 < 2%。两台都在预算内。带 * 的是 M4 最快档时间太少、按周期数估算的值。
- `docs/perf/network.md` 里 12:54 那一次出厂默认档是 M5 0.44%、M4 0.49%：当时网络清单每 60 s 强制重建，对全部接口逐个查 IOKit（每个约 1.9 ms，M5 上 40 个接口）。改成控制器类按接口缓存、接口列表没变就不重建之后，13:03 重测为上表的值（偏离记录）。同时确认了 90 s 内两台都没有收到任何 SCDynamicStore 变更通知，清单平时不会被通知频繁触发重建。
- 延迟开启后的单项开销：每个目标每次约 0.2 ms（CLI 实测），默认 5 s 一次。

## 4. 需要你亲手验收的部分

> 2026-10-17 用户验收：功能无问题。虚拟接口多时面板超出屏幕的版面问题交给合并模式（D63、K54）。


- 网速 widget 的位置、宽度与箭头样式；切换「单位」到比特 / 秒后的显示。
- 开一次代理软件的增强模式：面板主接口应仍为「以太网（en0）」并出现 VPN 标记；连接信息的 DNS 变成 198.18.0.2；网速 widget 不翻倍。
- 设置里开启延迟：确认没有弹出「本地网络」授权框；面板延迟卡片与 PING widget 有数；关闭后 PING widget 自动消失。
- 点「查询」公网 IP：第一次要求选择服务；之后点一次查一次（开代理时结果是代理出口）。
- 隐私页的「网络连接」一节是否把两个出站目标说清楚。
- 流量统计跑满一天后的「今日」数值（对照路由器或 `netstat -ib` 的差值）。
