# 电源设备模块验收报告

> 日期：2026-10-19。范围：D84（分支 `p1/power-devices`）。边界实测见 `power-devices-boundary.md`，规格与偏离记录见 `power-devices.md`。

## 结论（待用户验收）

- D84 列的内容已完成：
  - 数据：IOPS 设备清单（UPS、内置电池基础项、蓝牙配件，事件驱动）；UPS 的 HID 扩展遥测（负载与估算瓦数、输入 / 电池电压、状态位、额定值与阈值、自检结果、生产日期），用公开 IOHIDDevice，只读；
  - 界面：面板「电源」tab（无设备时在切换器里隐藏）、菜单栏「电源设备电量」widget（出厂关）、总览卡片、设置页、诊断页；
  - 历史：主 UPS 的电量、负载、输入电压每分钟；UPS 电池供电区间（schema 4）；导出写进 metadata；
  - CLI `devices`（`--watch` 供放电实测用）。
- 私有层新增两个符号（`IOPSCopyPowerSourcesByType`、`IOPSAccNotificationCreateRunLoopSource`），私有层版本 3。
- 偏离规格 7 处，见 `power-devices.md` §11。
- **待办**：PD8 放电实测（需要用户拔 UPS 市电 ≤ 60 s）；开销的一个疑点见 §2。

## 2. 开销（`docs/perf/power-devices.md`，D80 口径）

| 档位 | M5 | M4 |
|---|---|---|
| 出厂默认（widget 出厂关；后台多了电源设备历史：IOPS 60 s、HID 60 s） | 0.195–0.229%（4 次） | 0.102% |
| 面板打开（电源设备 tab，IOPS 1 s，HID 2 s） | 0.209% | 0.102%（无设备） |

- 预算：常驻 < 0.2%，面板打开 < 0.7%。面板档两台都在预算内；M4 出厂默认档与 10-18 的 1.0.0（0.099%）持平。
- M4 的测量经用户同意（2026-10-19）先结束了上面运行的 1.0.0 Release 实例（SIGTERM，正常收尾），测完后用 `open` 重新启动（D78）。
- **疑点**：出厂默认档与 `main`（1.0.0）交替测了 2 + 4 次：`main` 0.168%、0.195%，本分支 0.197%、0.200%、0.195%、0.229%，平均高约 0.02%（约 3 M 指令/s）。本机今天的波动也不小（同一份 `main` 两次差 0.027%）。
  - Release 构建的 60 s 对照采样（1 ms 一次）：非空闲样本 `main` 57、本分支 74，多出的样本散在主线程的 objc 消息、锁与 malloc 上，没有落在本模块的代码里；HID 读取与 IOPS 重建在采样里几乎看不到。
  - 已排除：HID manager 开着闲置（实测 20 s 不到 0.2 ms）；每分钟重开 HID（空闲关闭改为 180 s 后没有变化，改动保留）。
